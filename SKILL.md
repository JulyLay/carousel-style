# Стилістичний ключ каруселей Юлії Лайко

## Концепція

Мінімалізм + контраст. Чорний фон - це не порожнеча, це акцент.
Кожен слайд дихає. Текст - єдиний візуальний елемент на текстових слайдах.
Обкладинка зупиняє скрол через сильну фотографію з темним оверлеєм.

Референс-стиль: перевірена робоча формула.

---

## ВІЗУАЛЬНИЙ СТАНДАРТ

### Технічні параметри
- **Формат:** 9:16 вертикаль, 1080×1920px
- **Співвідношення сторін Instagram:** 4:5 (обрізка під стрічку - 1080×1350px)

### Колірна палітра
```
Фон слайдів:    #000000  (чистий чорний)
Основний текст: #FFFFFF  (білий)
Акцентний колір: #F5C518  (теплий жовтий / золотий)
Оверлей фото:   rgba(0,0,0,0.60)  (60% затемнення)
```

### Типографіка
```
Заголовок обкладинки: Inter ExtraBold / Neue Haas Grotesk Bold
                     UPPERCASE, білий, великий (≈72-90pt)
                     Максимум 3 рядки

Акцент (жовтий):     Inter SemiBold, sentence case
                     Використовується для 1-2 ключових фраз на слайд

Тіло тексту:         Inter Regular, білий, sentence case
                     18-22pt, міжрядковий 1.5
```

### Обкладинка (Слайд 0)
- Full-bleed фото людини - впевнена поза, читабельне обличчя
- Темний оверлей 55-65% поверх фото
- Текст позиціонується в нижніх 35-40% слайда
- Структура тексту обкладинки:
  ```
  [ГОЛОВНИЙ ЗАГОЛОВОК UPPERCASE]    ← білий, ExtraBold
  [ЖОВТИЙ АКЦЕНТ - коротка фраза]   ← жовтий #F5C518
  [Підтекст звичайним шрифтом]      ← білий, Regular
  ```

### Текстові слайди
- Фон: чистий чорний #000000
- Текст: білий, regular weight
- 1 слайд = 1 думка
- Максимум 4-5 рядків тексту
- Ключові слова/фрази - жовтим #F5C518
- Великі відступи зверху і знизу (білий простір = дизайн)
- Жодних іконок, рамок, декоративних елементів

## ПРОМТ-ШАБЛОН ДЛЯ NANO BANANA PRO

При генерації будь-якого візуалу для каруселей - додавай цей блок в кінець промта:

```
STYLE REQUIREMENTS:
Format: vertical 9:16, 1080x1920px
Color grade: deep rich blacks, warm amber highlights,
             cool blue undertones in shadows
Photorealistic, editorial quality, slight film grain
Cinematic depth of field
Mood: [визначається темою слайда]
NO text overlays, NO watermarks
```

## СЦЕНАРІЇ ЗАСТОСУВАННЯ

### Коли потрібен візуал-обкладинка
Використовуй реальну фотографію людини з теми каруселі.
Додавай темний оверлей у редакторі (Canva/Figma/Unfold).
Якщо фото немає - генеруй через Nano Banana Pro з промтом:

```
[Опис людини/сцени].
Cinematic portrait/scene, vertical 9:16 format.
Dark moody atmosphere, deep shadows.
Color grade: warm amber highlights, cool blue shadows.
Photorealistic, editorial photography style,
35mm film grain, shallow depth of field.
No text overlays.
```

### Коли потрібен візуал для смислового слайда
Використовуй темний/чорний фон сцени.
Об'єкт має бути добре читабельний на темному фоні.
Промт завжди закінчуй блоком STYLE REQUIREMENTS вище.

### Текстові слайди
Жодної генерації не треба. Просто: чорний фон #000000, білий текст, жовтий акцент #F5C518.
